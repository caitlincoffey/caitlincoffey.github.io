## Portfolio

- [Reverse Engineering with Ghidra](https://sites.google.com/view/ghidra-reverse-engineering/home#h.s1qs2m8gk4s9), a resource for people new to reverse engineering with some practice exercises included.
- [Connect4cks](https://github.com/sam-coleman/Connect_4), an AI that competitively plays Connect 4 using MiniMax with alpha-beta pruning. 
- [CPU to GPU Communication](https://comparch.goose.gay/), a resource explaining the architectural differences between the CPU and GPU, the hardware and software support of CUDA, and how GPGPU computing works (for a machine learning workload).

- [LC-3 Virtual Machine](https://github.com/caitlincoffey/SoftSysGarbageEaters), a reduced instruction set computer (RISC) written in C that can run .obj files on Linux/Unix systems.
- [Facial Recognition with PCA + K-Nearest Neighbors](https://docs.google.com/document/d/1BG8sD1TltkQV1XxtMYc9duJaeBcV_soT2BRhbC6S7EA/edit?usp=sharing), a facial recognition algorithm that detects one's age, race, and gender using principal component analysis, eigenvalue decomposition, and a K-nearest neighbors search.
